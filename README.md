# E-Commerce Website

A responsive fashion e-commerce website built with React.js, JavaScript, Bootstrap, and CSS. The project provides a complete shopping experience, from browsing products to adding items to a cart and completing checkout.

[View Live Website]

## 📌 About The Project

This project is a responsive e-commerce website designed for a fashion store. It was built to practice and demonstrate modern front-end development concepts using React.js.

The website includes multiple pages and reusable components, with navigation between different sections of the shopping experience.

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Home page with product sections
* Product listing and filtering
* Product details
* Add products to cart
* Mini cart functionality
* Shopping cart page
* Product quantity management
* Checkout page
* Discount code section
* Sign in page
* Sign up page
* Forgot password page
* Confirmation code page
* Dashboard

## 💻 Getting Started

To run this project locally, follow the steps below.

### 1. Clone the repository

```bash
git clone https://github.com/damilolapraise50-create/E-COMMERCE-WEBSITE.git
```

### 2. Navigate into the project

```bash
cd ReactProject
cd TorilloProject
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will then be available through the local development URL provided by Vite.

## 📦 Build For Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
